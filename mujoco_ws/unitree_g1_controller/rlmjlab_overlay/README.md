Place local RL-MJLab overlay files here.

This directory is copied into `/opt/unitree_rl_mjlab/` during the
`unitree_mujoco_dockerized` image build.

Use it for custom files that you do not want to keep in the external
`unitree_rl_mjlab` repository directly.

Examples:
- `deploy/robots/g1/config/...`
- `deploy/robots/g1/...`
